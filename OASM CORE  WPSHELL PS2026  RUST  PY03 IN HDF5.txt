============================================================
OASM CORE + PS-INSIDER HARDENED + RUST + PY03 IN HDF5
============================================================

PURPOSE
------------------------------------------------------------
Use HDF5 to organize the OASM core environment including:
- PS-Insider (hardened) integration
- Rust control layer
- Python 3 (Py03) scripting
while keeping everything modular, verifiable, repairable, auditable.

TOP-LEVEL STRUCTURE
------------------------------------------------------------
oasm_core.hdf5:

/core
  /ps_insider
  /rust
  /py03
  /cbor_layouts
  /schemas
  /templates
  /logging
  /tests
  /lineage
  /staging
  /kits   (for modular kits: compilers, CAD, scripting, etc.)

Each group holds base units (<100 LOC where possible), templates,
staged compositions, logging, tests, checksums, and lineage.
